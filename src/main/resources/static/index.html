A backend AI agents can set up for you.

BackendAsService is a Spring Boot + PostgreSQL Backend-as-a-Service that speaks MCP. Tell Claude what your app needs and it creates the project, collections, sample data and test users.

Demo server is up · this page is all there is to see in a browser; the rest is an API

Try it in 3 steps

  1. Get a developer token (sign up once, then log in) 
    curl -X POST https://baas-demo.onrender.com/auth/signup -H 'Content-Type: application/json' \
  -d '{"name":"You","email":"you@example.com","password":"your-password"}'
curl -X POST https://baas-demo.onrender.com/auth/login -H 'Content-Type: application/json' \
  -d '{"email":"you@example.com","password":"your-password"}'
  2. Connect Claude Code with the token from the login response 
    claude mcp add --transport http baas https://baas-demo.onrender.com/mcp \
  --header "Authorization: Bearer <token>"
  3. Ask Claude, in an empty folder 
    Create a backend for my book club app with sample data and a test user.

This is a free demo server: it sleeps when idle, so the first request can take up to a minute. Tokens last 24 hours. Don't store anything private here.
